# Quick Caption — מתקין בטא ל־Mac

חבילת בדיקה ל־Quick Caption QA. נדרשים Creative Cloud Desktop מותקן ומעודכן,
Premiere Pro 25.6 ומעלה, ו־macOS 13 ומעלה שמתאים לגרסת פרימייר המותקנת.
אותה חבילה מכילה קוד JavaScript וסקריפטים ללא בינאריים ייעודיים ל־Intel או
Apple Silicon; כלי ההתקנה של Adobe מגיע מה־Creative Cloud המקומי.

**החבילה עדיין לא נבדקה על Mac אמיתי, אינה חתומה ב־Apple Developer ID ואינה
מאושרת ב־notarization.** רכיב CEP בחבילה הנוכחית נחתם ואומת ב־Windows. Adobe
תיעדה תקלות חתימה בין פלטפורמות; אין כאן הבטחה ש־Adobe ב־Mac יקבל אותו.
סימולציות בודקות את המתקין והנתיבים, ולא את Gatekeeper, LaunchServices,
חתימת CEP במק, טעינת הפאנל, האודיו או הרינדור בפרימייר.

## התקנה

1. הורידו `QuickCaption-Installer-1.0.1-Mac-Beta.zip` וחלצו במק בלחיצה כפולה.
2. שמרו את הפרויקט וסגרו את פרימייר. פתחו Creative Cloud Desktop והתחברו ל־Adobe.
3. הפעילו `Quick Caption Setup.app` ולחצו **התקנה** בחלון.
4. אם macOS מציג הודעה שהמפתח אינו מזוהה או שאין אישור Apple, לאחר ניסיון
   הפתיחה אפשר לבחור **System Settings → Privacy & Security → Open Anyway**
   עבור המתקין הזה. זו הרשאה נפרדת לאפליקציה; אין לכבות Gatekeeper או להסיר
   quarantine באמצעות פקודות. במחשב מנוהל ייתכן שהארגון אינו מאפשר זאת.
   אם ההודעה אומרת שהאפליקציה פגומה או מזיקה, עצרו ושלחו את נוסח ההודעה.
5. אם חלון האפליקציה אינו מופיע, הפעילו `Install Quick Caption.command`
   מאותה תיקייה. ייפתח Terminal ולאחריו אותו חלון התקנה.
6. רק אם המתקין אישר ששני הרכיבים מותקנים ופעילים, פתחו את פרימייר ובחרו
   **Window → UXP Plugins → Quick Caption QA**. התחברו ל־Quick Caption ואשרו את החיבור.

המתקין משתמש ב־UnifiedPluginInstallerAgent הרשמי של Adobe כדי להתקין את קובצי
CCX ו־ZXP. הוא בודק את שלמות הקבצים, מסרב לפעול כשפרימייר פתוח ובודק גם את
תוצאת ההתקנה המודפסת ואת רשימת הרכיבים של Adobe. קוד יציאה 0 לבדו אינו הצלחה.
אם הוא נכשל לאחר התקנת רכיב אחד, הדוח מציין איזה רכיב הצליח; הרכיב לא נמחק
אוטומטית. מנהלים תיקון/התקנה מחדש דרך Adobe לאחר בירור התקלה.

אין צורך ב־Node.js, Python או UXP Developer Tools במחשב המשתמש. המתקין אינו
מפעיל מצב מפתח, משנה אימות חתימות, מבקש סיסמה באמצעות סקריפט, סוגר את פרימייר
או מוחק קבצי פרויקט. עדכונים של חבילות חתומות עוברים דרך מנגנון Adobe.
אם קיימת התקנת פיתוח לא חתומה בגשר CEP של המשתמש, המתקין עוצר ומשאיר אותה
במקום כדי שנוכל לגבות ולהעביר אותה לפני ניסיון נוסף.

אם מתקין נקטע בכוח, הוא משאיר נעילה כדי למנוע פעולות מקבילות. יש לוודא שאין
מתקין Quick Caption או פעולה של Adobe בתהליך, ואז להסיר רק את התיקייה הריקה:
`~/Library/Application Support/Quick Caption/Installer/install.lock`.
אין להסיר תיקיות הרחבות, פרויקטים או קבצי מדיה כדי לפתור נעילה.

## בדיקה ראשונה

בחרו קטע קצר עם דיבור בציר הזמן. התחילו עם כתוביות רגילות ללא מילה אקטיבית.
ודאו שהכתוביות מופיעות במקום הנכון, ואז בדקו שני קטעים ומילה אקטיבית.
תמלול משתמש בקרדיטים של חשבון QA כפי שמוצג בפאנל; המתקין עצמו אינו מתמלל.

מילה אקטיבית עדיין דורשת את תבנית Adobe המקורית **Classic Web Caption**.
התבנית וגופני Adobe אינם מצורפים לחבילה. אם היא חסרה, יש להשיג אותה דרך
ממשק תבניות הגרפיקה של Adobe. פונט, עברית, תזמון, עריכת ההדגשות ואודיו
דורשים בדיקה במק אמיתי לפני הפצה.

## דוח תקלה ממחשב אחר

כשל בהתקנה מופיע עם שלב, קוד Adobe ומזהה דוח. הפעילו
**Quick Caption Diagnostics.command** ובחרו **שמירת דוח**, ואז צרפו את קובץ
ה־JSON לשיחה הזאת. כך אפשר לקרוא כאן דוח מהמחשב של המק גם כשהפאנל לא נטען.
הוא מכיל מזהה, גרסאות, ארכיטקטורה, שלב, קודים ומצב שני הרכיבים; אין בו שם
משתמש, נתיבי מדיה, סיסמאות, מפתחות חיבור, טקסט תמלול או פלט גולמי של Adobe.

המקור הוא קובץ יחיד של פחות מ־8KB:
`~/Library/Application Support/Quick Caption/Installer/last-install.json`.
ניסיון נוסף מחליף אותו. LaunchAgent קטן למשתמש בודק אותו מדי שעה ומוחק אותו
אחרי שבעה ימים, גם בלי לפתוח שוב את המתקין; אם המחשב כבוי, בניסיון הבא אחרי
הפעלתו. המשימה מסירה את עצמה כשאין עוד דוח. השדה `cleanupScheduled` מציין אם
macOS אישר רישום של משימת המחיקה. אם לא, ניסיון תקין נוסף ינסה לרשום אותה,
וניתן להסיר את הדוח המקומי ידנית אחרי העברתו. העותק ששמרתם לתמיכה נשאר
באחריותכם עד שתמחקו אותו.

לכשל לפני התחברות **אין העלאה אנונימית לשרת**. מזהה הדוח לבדו אינו מאפשר
למצוא את דוח ההתקנה מרחוק; יש לצרף את הקובץ. אחרי התחברות לפאנל, דוחות
תקלות בזמן העבודה משתמשים במנגנון QA המאומת הקיים, וניתנים לשליפה כאן לפי
מזהה דיווח גם ממחשב אחר. הם מוגבלים בנפח ובכמות ונמחקים אחרי שבעה ימים.
המתקין לא מוסיף נקודת קצה, מסד נתונים או קובצי לוג בשרת.

## בנייה ובדיקות למפתחים

`node scripts/build-premiere-mac-installer.mjs` בונה את חבילת המק מתוך זוג
חבילות Adobe המאומתות ב־`artifacts/premiere-installer/`, מוודא checksum,
זהות וגרסת manifest, חתימת CEP קיימת והיעדר קבצים פרטיים, ומעתיק את הבתים
החתומים ללא שינוי. הוא אינו טוען שבדק חתימה במק או חתם את אפליקציית Apple.
ה־ZIP שומר הרשאות Unix 0755 למפעילים ו־0644 לקובצי נתונים. ב־build-info.json
מצוינים פלטפורמת החתימה וכל בדיקות המק שעדיין לא בוצעו.

לפני הפצה ציבורית צריך לבנות/לחתום את הגשר במק, לחתום ולבצע notarization
למתקין ב־Apple Developer ID, ולבדוק במק נקי Intel וב־Apple Silicon עם אימות
חתימות פעיל. כשמייצרים זוג CCX/ZXP חדש יש לעדכן את metadata וה־checksums
באמצעות תהליך הבנייה המאומת, ולא לשנות ידנית הרחבה חתומה.

בדיקות מקומיות: `node --test tests/plugin-mac-installer.test.mjs`.
הבדיקות מריצות פונקציות Bash עם גבולות macOS/Adobe מדומים; הן אינן מתקינות
דבר במחשב המקומי. סקריפטים תואמים לתחביר Bash 3.2, אבל כאן הורצו תחת Git Bash.

בדיקה ב־2026-10-10: 210 בדיקות התוסף והמתקינים עברו ב־Windows, מתוכן 31
בדיקות חדשות למתקין המק. בנוסף נבנתה החבילה מזוג חבילות Adobe האמיתיות
שאומתו בבניית Windows; שלמות שתי החבילות והרשאות ההפעלה ב־ZIP נבדקו.
לא בוצעו התקנה או רינדור במק, תמלול בתשלום או שינוי בשרת.

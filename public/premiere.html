גרסת בדיקה ל־Windows

המתקין טרם חתום בחתימת מפרסם של Windows. אם הדפדפן או Windows חוסמים אותו, שלחו לנו את נוסח ההודעה כדי שנוכל לבדוק. התוסף מתחבר לחשבון QA; תמלול צורך קרדיטים לפי המחיר שמוצג לפני השליחה.

גרסת בדיקה למאק

החבילה טרם נבדקה במאק אמיתי ואינה חתומה או מאושרת ב־Apple. רכיב Adobe נחתם ב־Windows, ולכן ההתקנה במאק עדיין דורשת אימות. התוסף מתחבר לחשבון QA; תמלול צורך קרדיטים לפי המחיר שמוצג לפני השליחה.

מתחילים כאן

התקנה, צעד אחר צעד

אין צורך ב־Node.js או בכלי פיתוח.

  1. מורידים את המתקין

    לחצו על הורדה ל־Windows. הקובץ נקרא QuickCaption-Setup-1.0.2-Windows.exe. אפשר למצוא אותו גם ברשימת ההורדות של הדפדפן.

  2. שומרים וסוגרים את Premiere

    שמרו את הפרויקט וסגרו את פרימייר לגמרי. פתחו את Creative Cloud Desktop והתחברו לחשבון Adobe שלכם.

  3. מפעילים את המתקין

    פתחו את קובץ ה־EXE שהורדתם ולחצו על התקנה. המשיכו רק אחרי שהמתקין מאשר ששני הרכיבים מותקנים ופעילים.

  4. פותחים את התוסף ומתחברים

    פתחו מחדש את Premiere ובחרו Window → UXP Plugins → Quick Caption QA. התחברו ל־Quick Caption ואשרו את החיבור בחשבון QA.

  1. מורידים ומחלצים

    הורידו את קובץ ה־ZIP וחלצו אותו בלחיצה כפולה. אם יש גרסה ישנה, השתמשו במתקין החדש כדי לעדכן.

  2. שומרים וסוגרים את Premiere

    שמרו את הפרויקט וסגרו את פרימייר לגמרי. פתחו את Creative Cloud Desktop והתחברו לחשבון Adobe שלכם.

  3. מפעילים את המתקין

    פתחו Quick Caption Setup.app ולחצו על התקנה. המשיכו רק אחרי שהמתקין מאשר ששני הרכיבים מותקנים ופעילים.

    אם חלון המתקין אינו מופיע, פתחו את Install Quick Caption.command מהתיקייה שחילצתם.

  4. פותחים את התוסף ומתחברים

    פתחו מחדש את Premiere ובחרו Window → UXP Plugins → Quick Caption QA. התחברו ל־Quick Caption ואשרו את החיבור בחשבון QA.

macOS חוסם את פתיחת המתקין?

אם ההודעה היא שהמפתח אינו מזוהה, נסו לפתוח פעם אחת ואז עברו ל־System Settings → Privacy & Security → Open Anyway עבור המתקין הזה. אין צורך לכבות את Gatekeeper או להריץ פקודות להסרת quarantine.

אם ההודעה אומרת שהאפליקציה פגומה או מזיקה, עצרו והעבירו לנו את נוסח ההודעה. במחשב של ארגון ייתכן שנדרש אישור מנהל המערכת.

למה התוסף מתחבר גם ל־localhost?

החשבון, הקרדיטים והתמלול מתקשרים עם שרת QA של Quick Caption באינטרנט. כדי להציב את הכתוביות בטיימליין, התוסף מתקשר גם עם רכיב שמותקן במחשב שלכם יחד עם התוסף.

localhost הוא המחשב שבו Premiere פועל — במאק, זה המאק שלכם. אין צורך בגישה למחשב של אדם אחר או בהתקנת שרת נפרד.

הבדיקה הראשונה

מתחילים מקטע קצר

סמנו קטע עם דיבור והתחילו עם כתוביות רגילות. ודאו שהכתוביות מופיעות במקום הנכון, ואז נסו שני קטעים והדגשת מילה פעילה.

להדגשת המילה הפעילה נדרשת תבנית Adobe המקורית Classic Web Caption. אם היא חסרה, הוסיפו אותה דרך ממשק תבניות הגרפיקה של Adobe. אפשר להתחיל עם כתוביות רגילות גם בלעדיה.

אם משהו נעצר

איך מדווחים על תקלה?

במהלך ההתקנה ב־Windows: שלחו את נוסח השגיאה ואת קובץ last-install.json מתוך %LOCALAPPDATA%\Quick Caption\Installer, אם נוצר.

במהלך ההתקנה במאק: פתחו Quick Caption Diagnostics.command, בחרו שמירת דוח ושלחו לנו את קובץ ה־JSON ואת נוסח השגיאה.

בתוך התוסף, לאחר התחברות: העתיקו את קוד האבחון שמופיע ליד השגיאה. הוא מאפשר לנו למצוא את דוח התקלה ב־QA.

דוח ההתקנה נשאר במחשב; מזהה הדוח לבדו אינו מספיק לשליפתו. אין צורך לשלוח קובצי פרויקט או מדיה.
